# 美版《宝可梦 绿宝石》中文源码实验

本分支以最新的 `pret/pokeemerald`（美版 Emerald 反编译）为基底，只移植中文显示能力，不引入 `pokeemerald-expansion` 的玩法和数据改动。

## 当前状态

- 可在 Linux 原生编译，不需要 Docker。
- 已加入卧看微尘方案兼容的双字节中文编码、10/12 像素中文字库及渲染、宽度计算。
- 字库及新增字表取自仍在维护的 `rh-hideout-chinese/pokeemerald-expansion`。
- 已汉化主菜单、原版设置菜单和新游戏开场的小田卷博士对话。
- 其余正文尚未导入；这是可继续汉化的源码基底，不是完整汉化成品。

## 构建

在本目录执行：

```bash
./scripts/build-chs-linux.sh
```

输出为 `pokeemerald_modern.gba`。`modern` 构建使用 devkitARM；它不是逐字节还原官方 ROM 的 matching 构建，但适合继续开发和测试。

## 资料来源与取舍

1. `Wokann/Pokemon_GBA_Font_Patch`：面向美版 R/S/FR/LG/E 的二进制字库补丁，适合研究 ROM 注入点。
2. `Wokann/pokeemerald` 的 `wokann/chs_patch`：最小源码实现。本分支沿用其双字节编码布局和原版渲染器接入方式。
3. `rh-hideout-chinese/pokeemerald-expansion`：当前最完整、仍维护的简体中文资源。本分支复用其较新的字库和字表；翻译文本需按符号逐项移植，不能整仓覆盖。
4. `Olcmyk/Meowth-GBA-Translator`：可用于从 ROM 抽取、编码和回写文本，但它是二进制翻译流水线，不是反编译源码的替代品。

## 可行性与限制

- Emerald：可行性最高。原版美版反编译完整，中文引擎已能独立编译，现有 expansion 汉化可作为主要语料库。
- FireRed/LeafGreen：字体补丁已有，但没有发现同等完整、可直接迁移到原版 `pokefirered` 的公开中文源码；需要另做引擎端口和文本迁移。
- Ruby/Sapphire：卧看微尘的二进制补丁最成熟，但源码汉化资源比 Emerald 少。
- 中文名在存档和联机协议中仍按“字节长度”计数，一个汉字占两字节。核心存档/联机结构未改变，但中文名字传到未打补丁的官方游戏会乱码，可输入长度也必须另行审计。
- 双字节前导字节复用了少见的西文重音字符编码。正常英文文本基本不受影响，但完整迁移前应做全仓编码冲突扫描。
- 上游项目、译文和字库各有自己的许可证/署名要求；发布 ROM 或补丁前应逐项确认，不应提交商业 ROM。

## 下一阶段

优先按声明符号迁移 `strings.c`、地图脚本、物品/招式/特性、图鉴和战斗文本；每批迁移后检查窗口宽度、换行、动态占位符、姓名输入、存档和联机。图片中的英文需要作为独立图形资源处理。
